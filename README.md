# Abs, Legs, Back

A guided home-workout web app: timed holds, rep logging, rest timer, levels, calorie diary. Installable on your phone.

## Put it online (GitHub Pages)
1. Create a new public repository on github.com.
2. Upload every file in this folder (index.html, manifest.webmanifest, sw.js, both icons) to the repository root.
3. Go to Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, and save.
4. After a minute your app is at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Install it
- iPhone: open the link in Safari, tap Share, then "Add to Home Screen".
- Android: open the link in Chrome, tap the menu, then "Install app" or "Add to Home screen".

Your history, levels and calories are saved in the browser on that phone.
